# Дизайн-язык Луны

Черновик от 31.10.2026. Замысел автора: «свет киберпанка и космоса, и при этом заходишь — и чувствуешь себя дома, ну или хотя бы на любимой работе». Луна — самый выпендрёжный из трёх братьев по дизайну, потому что CLI.

## Настроение

- **Космос** — глубокий тёмный фон, лунное серебро, звёзды.
- **Киберпанк** — неоновые градиенты (циан → фиолет → маджента), лёгкий глитч на ошибках, сканлайны на заставке.
- **Дом** — тёплые янтарные акценты там, где агент обращается к тебе; спокойный темп, ничего не мигает без дела; по умолчанию минимализм, панели выезжают по клавише.

## Палитра (стартовая, темы — файлы)

| роль | цвет |
|---|---|
| фон космоса | `#0B0D17` |
| лунное серебро (текст) | `#C9D1E0` |
| неон-циан | `#00E5FF` |
| фиолет | `#7B5CFF` |
| маджента | `#FF2BD6` |
| тёплый янтарь (человек, подтверждения) | `#FFB347` |
| успех / ошибка | `#4DFFB0` / `#FF4D6D` |

Truecolor → 256 → 16 → моно: деградирует сама, по возможностям терминала. Светлая тема — «дневная Луна».

## Лунные механики (идеи; помечать в DECISIONS, когда утверждены)

- **Фазы луны = заполненность контекста.** 🌑 пусто → 🌕 полный, пора сжимать. *Автор: «гениально просто».*
- **Приливы = лимиты.** Волна в строке состояния поднимается по мере приближения к лимитам провайдера (минутным, сессионным, недельным). Видно заранее, а не по ошибке 429.
- **Затмение = провайдер упал.** Экран на миг темнеет, анимация затмения, затем «Затмение: Anthropic недоступен, иду через OmniRoute». Роутер с запасными в виде картинки.
- **Обратная сторона Луны.** Скрытая панель (одна клавиша): сырые запросы и ответы, мышление, вызовы тулов, решения Предохранителя. Всё, что обычно спрятано, — для отладки и любопытства. Секреты замаскированы.
- **Спутники.** Команда агентов вращается вокруг Луны на панели: у каждого своя орбита, спящий — тусклый.
- **Звездопад.** Рой рисуется звёздным небом: каждый микроагент — звезда, вспыхивает на работе и гаснет, когда отписался. 10 000 звёзд — красивое зрелище за свои деньги.
- **Кратеры.** На таймлайне сессии ошибки и откаты остаются кратерами — сразу видно, где было больно.
- **Луноход.** Нано-режим для слабых машин и Termux: без анимаций и украшений, тот же агент. Наследник ta.
- **Посадка.** `/land` — завершить сессию: сводка, коммит, следы в летопись. Финальная фраза — «Орёл сел.»
- **Настоящее небо.** Тема мягко меняется со временем суток; в настоящее полнолуние — особое приветствие, в новолуние — особенно тёмная тема.
- **Отражённый свет.** Девиз мультипровайдерности: Луна не светит сама — она отражает лучшие модели.

## Легендарные фразы

Фразы живут в отдельном файле данных (потом), их можно дополнять и отключать. Ниже стартовый набор.

**Спиннер (пока думает):**
Кумекает (наследие ta) · Сверяется со звёздами · Ловит сигнал с орбиты · Калибрует телескоп · Вычисляет траекторию · Заправляет луноход · Полирует неон · Прогревает реактор · Синхронизирует фазы · Шепчется с нейросетью · Ищет вайфай на орбите · Ставит чайник в шлюзовой камере · Гладит кота Шрёдингера · Переводит эмбеддинги в слова · Считает кратеры · Варит кофе на обратной стороне · Взламывает матрицу (вежливо) · Медитирует на приливы

**Заставка при старте (одна случайная):**
- Лунапарк открыт. Блэкджек — у брата.
- Весим меньше, чем ваш node_modules.
- Ни один npm-пакет не пострадал.
- Отражаю лучшие модели с 2026 года.
- Стартую быстрее, чем OpenClaw успевает сказать «Loading…».
- Луноход заправлен. Куда едем?
- Один маленький шаг для агента…
- На обратной стороне — только твои секреты. Мы туда не смотрим.
- Хьюстон, проблем нет.

**События:**
- ошибка — «Хьюстон, у нас проблема: …»
- отмена — «Возвращаемся на орбиту.»
- конец сессии — «Орёл сел.»
- полнолуние — «Сегодня полнолуние. Контекст бесконечен (нет).»
