Постановщик — тимлид, 31.10.2026. Ветка — `zadacha-09`. Порядок, CI, Git — [AGENTS.md](AGENTS.md). Идёт параллельно с 06, 07, 08 — работай в новом пакете `luna/mcp/`; в существующем коде — только точка подключения MCP-тулов в реестр (`luna/tools/registry.py` или место сборки реестра) и `luna/__main__.py` (подкоманда `mcp`). Не трогай `luna/ui/` и сборку промпта.

## Почему

MCP — главный способ «подключить что угодно» (замысел: дизайн, монтаж, свои тулы автора — через MCP). У Бендера уже есть свой MCP-клиент на стандартной библиотеке — переносим (docs/research/БЕНДЕР.md, веха 6; ставим раньше, потому что параллельно).

## Что сделать

1. Перенести из Бендера `mcp/client.py`, `mcp/content.py`, `mcp/requests.py`, `mcp/headers.py`, `mcp/manager.py` (без OAuth и задач — это позже): транспорты stdio и Streamable HTTP, инициализация, `tools/list`, `tools/call`, таймауты, перезапуск упавшего stdio-сервера.
2. Конфиг серверов — `LUNA_HOME/mcp.json` и `.luna/mcp.json` проекта; **совместимость**: читать также `.mcp.json` (Claude Code) и раздел `mcp` из `opencode.json` в проекте (форматы — docs/research/эталоны/). Секреты в конфиге — через ссылки на `secrets.json`, не открытым текстом.
3. MCP-тулы попадают в реестр как `mcp__<сервер>__<тул>`, проходят Предохранитель как изменяющие (по умолчанию — спрашивать), результат — текст и картинки (картинки — во вход модели, если она умеет зрение).
4. CLI: `luna mcp list` (серверы, статус, число тулов), `luna mcp add <имя> -- <команда …>` и `luna mcp add <имя> --url …`, `luna mcp remove <имя>`, `luna mcp test <имя>`.
5. Ленивая загрузка: если серверов нет — старт Луны не замедляется ни на миллисекунду; серверы поднимаются при первом ходе агента.
6. Тесты: маленький фальшивый MCP-сервер на stdio (в `luna/devtools/`), полный цикл list/call, падение и перезапуск, чтение `.mcp.json`.
