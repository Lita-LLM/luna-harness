## 2. Команды

Сейчас у Луны: `/mode /clear /help /exit /copy /sessions /new /rename /manners /undo /rewind /redo /compact /panels /panel /layout /todo`, `!команда`, `@файл`, Esc Esc, Tab/Shift+Tab, Ctrl+O, Ctrl+T, Alt+буквы панелей. Кандидаты (проверь по описи, добавь найденное):

- `/model` (выбиралка моделей по ролям, на лету), `/cost` и `/usage` (деньги и токены сессии), `/context` (из чего состоит контекст: промпт, инструкции, тулы, история — по долям), `/status`, `/doctor` (в чате), `/init` (сделать `AGENTS.md` для проекта — агентом), `/memory` (открыть инструкции проекта в редакторе), `/review` (ревью текущего диффа), `/export` (сессия в markdown), `/add-dir`, `/mcp` (выбиралка серверов: статус, вкл/выкл, тулы), `/agents` (заглушка-выбиралка под ЗАДАЧУ-11), `/theme`, `/editor` (написать сообщение во внешнем редакторе), `/details` (переключить подробности), `/btw` или аналог (вопрос в сторону, не сбивая ход), `/bug` (собрать отчёт об ошибке: версия, лог без секретов — в файл).
- Клавиши: Ctrl+R — поиск по истории ввода; ↑/↓ — история ввода; Esc Esc на пустом вводе — к `/rewind` выбиралкой; Ctrl+L — перерисовать; Ctrl+V — вставка картинки, если терминал/буфер умеют; vim-режим ввода (выключатель).
- Всё, где выбор, — на общей выбиралке (`picker.py`). Меню-цифры в `/panels` замени выбиралкой.
- `/help` — не простыня, а выбиралка с поиском по командам и клавишам; Tab после `/` дополняет команды с описанием.

## 3. Тайлы

Движок панелей есть (`luna/ui/panels.py` + `luna/ui/panels/`), панели: план, Луна, Лимиты, Обратная сторона, Файлы, Ниблер. Добавь (по описи эталонов + здравому смыслу):

- **Контекст** — из чего состоит, по долям, с крупнейшими сообщениями; кандидаты на сжатие.
- **Git** — ветка, изменённые файлы, дифф по Enter, последние коммиты.
- **MCP** — серверы, статус, тулы, ошибки подключения.
- **Процессы** — фоновые команды агента (`bash` с фоном пишет лог в `output_dir`): живы/завершены, хвост вывода, остановить.
- **Дерево файлов** проекта с пометками изменённых сессией, Enter — `@файл` в ввод.
- **Модели** — роли, что настроено, живо ли (`luna models`), задержка последнего ответа.
- **Диагностика** — ошибки и предупреждения: если в проекте есть линтер/компилятор — вывод последнего прогона (без LSP пока, LSP — отдельная веха).
- Статус-строка: настраиваемая (что показывать — настройкой), как statusline у Claude Code.

Каждая панель — модуль через `register_panel`, данные — из событий и дешёвых опросов **только пока панель открыта** (ЦП в простое ~0). Меню панелей и Alt-клавиши подхватывают новые сами.

## Как потрогать

- `luna try chat` — новые команды и панели на фальшивом агенте.
- `luna try snapshot panels` / `help` / новые экраны — HTML-снимки. Снимки делай с часами `_FAKE_NOW` (см. `app._clock` в `luna/devtools/snapshot.py`), иначе на долго работающих машинах текст проявляется в прозрачность.
