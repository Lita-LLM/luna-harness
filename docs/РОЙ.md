# Ассистенты, Спутники, Звездопад

Проект роя Луны. Слова автора — [ЗАМЫСЕЛ.md](../ЗАМЫСЕЛ.md), «Уточнения», 1 ноября 2026. Решения тимлида по тому, что автор отдал на его усмотрение, помечены «(тимлид)». Задачи по этому документу — `ЗАДАЧА-11`, `ЗАДАЧА-15`, `ЗАДАЧА-16`.

Эталоны (ноябрь 2026): субагенты и экспериментальные «команды» Claude Code (тиммейты — отдельные экземпляры, пишут друг другу напрямую), субагенты Codex (TOML-профили, пакетная обработка), команды в OpenCode от сообщества (разные провайдеры в одной команде). Роя на десятки–тысячи агентов с правилами нет ни у кого — это наше поле.

## 1. Три вида, один движок

Все трое — тот же `Agent` (`luna/mind/loop.py`): свой промпт, тулы, модель, бюджет, свои события на общей шине с полями `agent_id` и `parent_id`.

| | Ассистент | Спутник | Ячейка роя |
|---|---|---|---|
| Что это | временный, но полноценный агент, экономная опция | член постоянной команды | одноразовый микроагент |
| Живёт | до сдачи задания | всю сессию, может спать | секунды–минуты, TTL |
| Возможности | полные (как у хозяина) | полные, свои роль и модель | по профилю ячейки |
| Подтверждения | через Предохранитель хозяина, вопрос помечен, от кого | так же | нет: что вне профиля — отказ, человека не спрашивают |
| Почта | только хозяин ↔ ассистент, по имени | все со всеми по именам, есть лидер | по адресам, по правилам роя |
| Пример | «разберись с этим логом» | Тимлид, Кодер1, Ревьюер | `leo/rev.3.12` |

Хозяин видит **сводку** от ребёнка, а не весь его лог — контекст хозяина не пухнет. Полный лог — в панели «Обратная сторона» и на диске.

## 2. Права

- **Права ребёнка ⊆ права родителя.** Нельзя выдать больше, чем есть у самого.
- **Размножение** — единственное, что задано строго для всех. По умолчанию звать ассистентов, спутников и рой могут только **полноценные агенты**: главный агент Луны и его спутники. Ассистенты и ячейки — не могут. Настройка `agents.max_depth` (по умолчанию 1: только полноценные зовут детей; 2 — дети тоже могут, и т.д.) и флаг в профиле ячейки.
- **Запись в файлы** — режим профиля:
  - `none` — только читать;
  - `sandbox` — своя папка роя (`output_dir/<рой>/`), по умолчанию;
  - `worktree` — свой git worktree на ячейку или на звено, сливает хозяин;
  - `project` — прямо в проект. Только если у хозяина есть это право и человек подтвердил при запуске роя.
- Запуск роя — **одно действие** хозяина, оно проходит Предохранитель как любое: подтверждение со сметой (сколько ячеек, профили, модели, режим записи, оценка денег и времени). В авто-режиме — без подтверждения, но в пределах потолков.

## 3. Почта

- **Спутники** пишут друг другу по именам (`Клод → Муза`, `Кодер1 → Тимлид`), «пинают» (будят спящего), можно назначить лидера. У каждого — входящие, сообщение будит спящего.
- **Ассистенты** — только с хозяином: от хозяина по имени, ответ — только хозяину.
- **Рой** — по адресам (раздел 4). Кто кому может писать, задаёт хозяин при запуске выбором схемы:
  - `none` — ячейки молчат, сдают результат;
  - `tree` (по умолчанию) — ячейки → звеньевой → хозяин. Звеньевой сворачивает отчёты звена (кодом, если свёртка механическая, или ячейкой-сборщиком), поэтому хозяин получает десяток сводок, а не тысячу сообщений;
  - `board` — общая доска: ячейки читают и пишут заметки, хозяин читает сводку доски;
  - `neighbors` — соседи по звену;
  - `rules` — свои правила (раздел 6).
- Любая почта — события шины (`agent.message`), панель рисует их как связи между звёздами.

## 4. Адреса в рое (тимлид)

Из вариантов Gemini взят «тактический IP», но по-лунному. Рой называется **метеорным потоком**: Персеиды, Леониды, Геминиды, Лириды, Ориониды, Квадрантиды… Первый рой сессии — по ближайшему к сегодняшней дате настоящему потоку, дальше по кругу.

```
leo/rev.3.12
 │   │   │ └─ индекс в звене
 │   │   └─── звено (группа под одним звеньевым)
 │   └─────── каста — короткое имя профиля ячейки (rev, cod, cls, web…)
 └─────────── поток — имя роя (leo = Леониды)
```

- Произносится: «Лео, рев три-двенадцать». Звеньевой — индекс 0: `leo/rev.3.0`. Сам хозяин потока — `leo/0`.
- Маска плотности, как у подсетей, — для красоты в панели и логах: `leo/12` — рой до 100 ячеек, `leo/34` — до 10 000.
- В коде имена латиницей, в интерфейсе — как угодно (с переводом потоков).

## 5. Профили ячеек

Профиль — данные (файл как у манер): встроенные в программе, свои — в `LUNA_HOME/cells/` (на весь харнесс) или только в памяти сессии.

- Поля: имя и каста, описание, модель (роль, конкретная модель или **пул** — см. раздел 7), промпт, разрешённые тулы, режим записи, вход и выход (схема — по желанию: одна ячейка может принимать текст, файл или JSON и отдавать что угодно), TTL, бюджет на ячейку, может ли размножаться, схема почты.
- **Создаёт и ИИ, и человек.** Хозяин делает профиль тулом на лету («нужна ячейка, которая размечает отзывы по тональности») — для сессии без подтверждения, сохранить на весь харнесс — с подтверждением. Человек — интерактивно, выбиралкой из ЗАДАЧИ-10 и словами; руками файл писать не обязательно.
- Встроенные профили (стартовый набор, расширяется):

| Каста | Что делает | Запись |
|---|---|---|
| `rd` читатель | читает и ищет по файлам, отвечает по ним | none |
| `web` разведчик | ищет и читает веб | none |
| `cls` классификатор | размечает элементы по категориям | none |
| `ext` извлекатель | достаёт структуру (поля, сущности) из текста | none |
| `sum` пересказчик | сжимает кусок в сводку | none |
| `tr` переводчик | переводит | sandbox |
| `rev` ревьюер | смотрит код или текст, находит проблемы | none |
| `aud` аудитор | ищет уязвимости в **своём** коде проекта, только чтение | none |
| `tst` тестировщик | пишет и гоняет тесты | worktree |
| `cod` кодер | правит код | worktree |
| `jdg` судья | сравнивает варианты, ставит оценки | none |
| `col` сборщик | сворачивает отчёты звена | none |
| `th` мыслитель | без тулов, только думает | none |

## 6. Рой по правилам (позже, вместе с Миссиями)

Автор: «рой как система с детерминированными правилами» — для автономного ресёрча и Миссий. Первая версия роя — раздать-собрать с деревом звеньев и доской. Следом — правила как данные: касты с ролями в построении, автомат «получил сообщение такого вида → сделай это → отправь туда», шаги по тактам. Это ложится на формат Миссий (граф в JSON) — проектировать вместе с вехой 7, сейчас только не закрыть дорогу: почта и касты — общие кирпичи.

## 7. Масштаб, модели, деньги (тимлид)

- Реалистично у автора — 50–70 ячеек на маленьких моделях с распределённым инференсом по узлам SUSPECT. Архитектура при этом обязана тянуть 10 000 на фальшивой модели: очередь заданий + пул исполнителей, а не поток на ячейку; память на ячейку — копейки.
- **Пул моделей**: в роутере несколько OpenAI-совместимых адресов одной модели (узлы сети) — ячейки раскладываются по ним по свободе. Это и есть «распределённый инференс» со стороны Луны.
- Ограничитель скорости на каждого провайдера и адрес: параллельность сама снижается по 429 и растёт обратно.
- **Деньги**: общий бюджет сессии `agents.session_budget_usd` (по умолчанию $5) — в него считаются все дети; потолок одного роя `starfall.budget_usd` ($1); на локальных моделях денег нет — считаем токены и время. Упёрлись — рой останавливается и отдаёт, что успел.
- **Смета**: перед запуском — пробный прогон на 3 входах, цена и время одного × N. Во время работы — прогноз остатка по фактической скорости.
- Живучесть: результаты пишутся на диск по мере готовности, рой продолжается после сбоя, упавшие задания перезапускаются.

## 8. Как это видно

- **Панель денег и лимитов**: статистика по каждому агенту (токены, деньги, время, шаги) и прогноз: «рой закончит через ~3 мин, ещё ≈ $0.40».
- **Панель «Созвездие»** — рой звёздами. Шрифт Брайля даёт 2×4 точки на клетку: панель 80×20 — это 12 800 точек, хватит на всех. Состояния:
  - действует — яркое мерцание;
  - думает — тусклое медленное мигание;
  - ждёт — ровный тусклый свет;
  - сдал — гаснет со следом-метеором;
  - упал — красная;
  - спит (спутник) — еле видна.
  - Почта — бегущая точка или линия между звёздами; в большом рое — между звеньями.
  - Enter на звене — приближение до отдельных ячеек с адресами и состоянием.
- **Спутники** — отдельный список с именами, ролями, статусом и почтой.
- Дальше: веб-фронтенд Луны (веха 8) — там созвездие можно сделать по-настоящему; картинки в терминале (kitty/sixel) — по желанию, Брайль — основа.
