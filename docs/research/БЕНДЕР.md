# Что берём у Бендера

Карта заимствований от 31.10.2026 по дереву `Nickup22/BENDER` (ветка по умолчанию). Решение автора: «можно сильно» тырить. Бендер — тоже Python 3.10+ на стандартной библиотеке, так что модули переносятся почти как есть.

## Как переносить

- Копируй файл целиком, потом режь лишнее (телеграм, сон, сердце, память Бендера — Луне не нужны в ядре). Не тащи зависимости по цепочке без нужды: если модуль тянет половину Бендера — перенеси только нужную часть.
- Переименуй `bender` → `luna` в импортах, путях, переменных окружения (`BENDER_*` → `LUNA_*`).
- В заголовке перенесённого модуля одна строка-комментарий: `# Перенесено из BENDER: bender/core/bus.py (коммит <sha>)` — чтобы потом сверять и подтягивать исправления.
- Тесты Бендера к перенесённому модулю тоже переносить, если они есть.
