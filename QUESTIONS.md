# Вопросы

Места, где замысел неясен. Рядом — вариант, который тимлид предлагает пока. Когда автор отвечает, ответ записывается сюда, а решение переезжает в DECISIONS.md.

## Открытые

1. **Порядок вех 2–7.** В черновике сначала красота, потом сессии, самоосознанность, рой, расширения и миссии. Может, автору важнее раньше получить рой или миссии?
2. **Формат Миссий.** Предложение: JSON-граф шагов (читается и людьми, и агентами, можно рисовать редактором) плюс возможность шага на Python. Или сразу Python-скрипт с маленьким API?
3. **Звездопад: потолки по умолчанию.** Предложение: смета и подтверждение всегда, потолок по деньгам на запуск — $5, параллельность — 64 (телефон — 8). Меняется в настройках.
4. **Глубина совместимости.** Что важнее всего «подружить»: инструкции и скиллы Claude Code, MCP-конфиги, импорт сессий, запуск Claude Code / Codex как движков, ACP для редакторов? Список уточнится исследованием эталонов.
5. **Общий код с братьями.** Копировать модули Бендера (провайдеры, роутер, MCP, Предохранитель) или со временем вынести общее в отдельную библиотеку-«ядро» для трёх проектов? Предложение: пока копировать, общее выносить, когда станет ясно, что именно общее.
6. **Песочница.** Подтверждения и ревизор, как в ta, плюс bwrap/Landlock, как у Бендера, на Linux. Устроит?

## Закрытые

- **Язык** → Python 3.10+, только стандартная библиотека (DECISIONS, 31.10.2026).
- **Интерфейс** → ядро-сервер плюс клиенты, по умолчанию минимализм (DECISIONS, 31.10.2026).
- **Команда и рой** → Спутники и Звездопад (DECISIONS, 31.10.2026).
- **Дизайн и монтаж** → в базе хорошее зрение у каждого провайдера и Миссии; узкие тулы — через MCP и позже (ЗАМЫСЕЛ, уточнения).
- **Подписки** → только легальные, остальное через OmniRoute (DECISIONS, 31.10.2026).
- **Что бесит в эталонах** → поломки и неудобная настройка; ответ — самоосознанность (DECISIONS, 31.10.2026).
