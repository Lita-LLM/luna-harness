# Бесплатный встроенный поиск (ПОИСК)

Исследование к ЗАДАЧЕ-19, факты сверены поиском по официальным
источникам 2026-11-01. Реализация — `luna/net/search.py`: цепочка
провайдеров настройки `web.search_providers`, единый формат ответа
тула (заголовок, адрес, выдержка, источник), провал одного — следующий
по цепочке, итог честный.

## Как у эталонов

- **OpenCode** встроенным websearch зовёт hosted MCP Exa
  (`https://mcp.exa.ai/mcp`) — бесплатно без ключа.
- **OpenClaw** держит цепочку провайдеров: Brave (ключ), Perplexity,
  Exa, Tavily, Gemini/Grok search, Parallel Search (бесплатный hosted
  MCP), DuckDuckGo, Ollama Web Search, SearXNG. Бесплатный Parallel
  в OpenClaw сам не выбирается — включается одной настройкой
  (`tools.web.search.provider = parallel-free`).

У Луны цепочка по умолчанию: `searxng` (если задан свой адрес) →
`exa` → `parallel` → `duckduckgo` → `brave` → `tavily` →
`perplexity`, плюс родной поиск последним резервом при
`web.native_search`.

## Exa (hosted MCP)

- Адрес: `https://mcp.exa.ai/mcp`, транспорт Streamable HTTP.
- **Без ключа работает**: режим без ключа — свободный rate limit,
  регистрация и API-ключ не нужны. Тулы по умолчанию: `web_search_exa`
  (query + objective, numResults) и `web_fetch_exa`; расширенный
  `web_search_advanced_exa` включается параметром `?tools=`;
  `agent_run` требует OAuth или ключ.
- С ключом (заголовок `x-api-key`): лимиты — по плану ключа. Новым
  аккаунтам дают стартовые кредиты ($20 по обзорам).
- Ключ в Луне: `luna setup` → сейф, имя `search:exa`.

Источники: https://docs.exa.ai и https://exa.ai/mcp (официальные),
проверено 2026-11-01.

## Parallel Search (hosted MCP)

- Адрес по документации: `https://search.parallel.ai/mcp` (это
  умолчание Луны, настройка `web.parallel_url`); в установочном посте
  блога Parallel фигурирует `https://mcp.parallel.ai/mcp` — адреса
  расходятся между официальными страницами, при сбое меняется
  настройкой. Вариант с OAuth — `…/mcp-oauth`.
- **Бесплатно без аккаунта и ключа** («free for agents»): тулы
  `web_search` (objective естественным языком + список search_queries;
  отдаёт ранжированные адреса с выдержками; несколько запросов одним
  вызовом) и `web_fetch` (до 20 адресов, ≈25 000 знаков на вызов).
- Ключ (Bearer) или OAuth поднимают лимиты; точные числа бесплатного
  тарифа официально не опубликованы — описан как «щедрый для личного
  использования».
- Ключ в Луне: сейф, имя `search:parallel` (поддерживается цепочкой,
  setup пока спрашивает только Exa/Brave/Tavily/Perplexity).

Источники: https://docs.parallel.ai и блог parallel.ai (официальные),
проверено 2026-11-01.

## Остальные звенья

- **SearXNG** — свой инстанс человека (самохостинг): JSON-выдача,
  никаких чужих лимитов; в цепочке — только если задан
  `web.searxng_url`.
- **DuckDuckGo** — резерв: разбор публичной HTML-выдачи обычным
  клиентом Луны. Это не официальный API: поисковик вправе не отвечать
  автоматическим запросам, тогда звено честно падает и цепочка идёт
  дальше. Под браузер не маскируемся, защиту не обходим — таково
  условие задачи.
- **Brave Search / Tavily / Perplexity** — официальные API, только по
  ключам (`luna setup` → сейф: `search:brave`, `search:tavily`,
  `search:perplexity`). Без ключа звено пропускается молча, а не
  падает.

## Родной поиск провайдера модели

У провайдеров есть свой поиск: Gemini grounding, OpenAI Responses
web search, серверный `web_search` Anthropic. Это отдельные тулы на
стороне провайдера со своей тарификацией; Луна держит их за
выключателем `web.native_search` (по умолчанию выключен). Честно
включён сейчас один путь: OpenRouter — та же главная модель с
суффиксом `:online`; для остальных провайдеров звено честно говорит,
что включать не умеет.

## Условия и на что переключаться

- Hosted MCP Exa и Parallel используются по их публичным условиям:
  бесплатный режим — в пределах их rate limit; никаких обходов,
  подмены заголовков браузера и прочего в Луне нет.
- Перестало хватать бесплатного: 1) поднять ключ Exa (лимиты плана);
  2) свой SearXNG первым звеном; 3) ключные Brave/Tavily/Perplexity
  официальными API; 4) родной поиск модели (`web.native_search`) —
  платится провайдеру модели.
