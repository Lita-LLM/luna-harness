# Вопросы

Места, где замысел неясен. Рядом — вариант, который тимлид предлагает пока. Когда автор отвечает, ответ записывается сюда, а решение переезжает в DECISIONS.md.

## Открытые (к первому планированию)

1. **Язык реализации.** Предложение: Python 3.10+ на одной стандартной библиотеке, как у Блэкджека и Бендера. Плюсы: можно брать готовые куски у братьев (провайдеры, роутер, MCP, Предохранитель), есть в Termux, ничего не компилируется, агентам легко править. Минусы: старт ~100–200 мс, а не мгновенный, и нет единого бинарника. Альтернатива — Go (один статический файл на 10–15 МБ, мгновенный старт, кросс-компиляция под Termux), но тогда ничего у братьев не переиспользовать. Замысел говорит «более удобный язык», чем bash. Ждём выбора автора.
2. **Интерфейс.** Предложение: сначала терминал (TUI, как ta и Claude Code), с первого дня оставить место под веб-пульт (как у братьев) и режим без интерфейса для скриптов и CI. Нужен ли десктоп или мобильный интерфейс?
3. **Что значит «ничем не уступать эталону».** Какие фичи Claude Code / Codex / OpenCode обязательны в первой вехе, а какие автор считает бесполезными? Кандидаты: субагенты и рои, план-режим, чекпоинты и откат, хуки, скиллы, MCP, LSP, worktree, фоновые задачи, веб-поиск, чтение картинок и PDF, сжатие контекста, сессии и продолжение, слэш-команды, удалённый режим.
4. **«Дизайн, анализ, монтаж».** Что из этого требует особых тулов? Например: превью HTML в браузере, работа с картинками, видео через ffmpeg (внешняя программа, не зависимость), таблицы.
5. **Связь с Бендером.** Может ли Бендер вызывать Луну как движок для разовых задач (он уже умеет запускать Claude Code как движок)? Общий формат провайдеров и настроек с братьями?
6. **Подписки и OAuth.** Подключать ли подписки (Claude, ChatGPT) или только ключи API и локальные модели? У Бендера тот же вопрос про риск бана.
7. **Песочница.** Уровень изоляции команд: подтверждения как в ta, ревизор-модель, bwrap/Landlock как у Бендера?
