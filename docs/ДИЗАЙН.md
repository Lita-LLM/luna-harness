# Дизайн-язык Луны

Черновик от 31.10.2026. Замысел автора: «свет киберпанка и космоса, и при этом заходишь — и чувствуешь себя дома, ну или хотя бы на любимой работе». Луна — самый выпендрёжный из трёх братьев по дизайну, потому что CLI.

## Настроение

- **Космос** — глубокий тёмный фон, лунное серебро, звёзды.
- **Киберпанк** — неоновые градиенты (циан → фиолет → маджента), лёгкий глитч на ошибках, сканлайны на заставке.
- **Дом** — тёплые янтарные акценты там, где агент обращается к тебе; спокойный темп, ничего не мигает без дела; по умолчанию минимализм, панели выезжают по клавише.

## Мягкость (отзыв автора на веху 0: «слишком жёсткий, угловатый»)

- **Скругления везде:** `╭╮╰╯` и тонкие линии `─│`; никаких двойных `═║` и сплошных блоков-кирпичей. Рамки — редкость: группировку чаще дают отступы и цвет фона, а не линии.
- **Воздух:** поля по краям, пустые строки между блоками, текст не прилипает к рамке.
- **Плавные градиенты:** много опорных точек, с переходом в фон по краям (виньетка), а не резкие полосы. Тени и полутона блоками `░▒▓` — только как мягкое свечение, не как заливка.
- **Полублоки ради гладкости:** `▀▄` удваивают вертикальное разрешение — луна, свечение и градиенты становятся круглыми, а не ступенчатыми.
- **Луна на заставке — круглый диск, а не ступенчатый многоугольник** (это и было «угловато»). Как:
  - рисовать полублоками `▀`: у каждой клетки два «пикселя» (верхний — цвет текста, нижний — фон), разрешение по вертикали вдвое выше, и клетки становятся почти квадратными пикселями;
  - сглаживать край: для пикселя на границе считать долю покрытия диском (несколько подвыборок) и смешивать цвет луны с фоном по этой доле — мягкий край вместо зубцов;
  - терминатор (граница света и тени у фазы) — тоже плавный градиент, а не резкая линия; на тёмной части — едва видный пепельный свет;
  - вокруг — мягкое свечение (ореол), затухающее в фон;
  - поверхность — 3–5 размытых кратеров чуть темнее, без контуров;
  - восход — плавно, с замедлением в конце (ease-out), без рывков по клеткам.
  - Без эмодзи-шрифтов: всё — цветом, поэтому работает в любом терминале с truecolor; на 256 цветах — то же с дизерингом.
- **Движение плавное:** easing (ease-in-out) вместо линейных рывков, появление через затухание, спиннер не дёргается.
- **Приглушённый неон:** яркие цвета — только акценты (курсор, важное); основной текст и фон спокойные.

## Палитра (стартовая, темы — файлы)

| роль | цвет |
|---|---|
| фон космоса | `#0B0D17` |
| лунное серебро (текст) | `#C9D1E0` |
| неон-циан | `#00E5FF` |
| фиолет | `#7B5CFF` |
| маджента | `#FF2BD6` |
| тёплый янтарь (человек, подтверждения) | `#FFB347` |
| успех / ошибка | `#4DFFB0` / `#FF4D6D` |

Truecolor → 256 → 16 → моно: деградирует сама, по возможностям терминала. Светлая тема — «дневная Луна».

## Лунные механики (одобрены автором 31.10.2026)

- **Фазы луны = заполненность контекста.** 🌑 пусто → 🌕 полный, пора сжимать. *Автор: «гениально просто».*
- **Приливы = лимиты.** Волна в строке состояния поднимается по мере приближения к лимитам провайдера (минутным, сессионным, недельным). Видно заранее, а не по ошибке 429.
- **Затмение = провайдер упал.** Экран на миг темнеет, анимация затмения, затем «Затмение: Anthropic недоступен, иду через OmniRoute». Роутер с запасными в виде картинки.
- **Обратная сторона Луны.** Скрытая панель (одна клавиша): сырые запросы и ответы, мышление, вызовы тулов, решения Предохранителя. Всё, что обычно спрятано, — для отладки и любопытства. Секреты замаскированы.
- **Спутники.** Команда агентов вращается вокруг Луны на панели: у каждого своя орбита, спящий — тусклый.
- **Звездопад.** Рой рисуется звёздным небом: каждый микроагент — звезда, вспыхивает на работе и гаснет, когда отписался. 10 000 звёзд — красивое зрелище за свои деньги.
- **Кратеры.** На таймлайне сессии ошибки и откаты остаются кратерами — сразу видно, где было больно.
- **Луноход.** Нано-режим для слабых машин и Termux: без анимаций и украшений, тот же агент. Наследник ta.
- **Посадка.** `/land` — завершить сессию: сводка, коммит, следы в летопись. Финальная фраза — «Орёл сел.»
- **Настоящее небо.** Заставка восходит с **настоящей фазой луны на сегодня** (синодический месяц 29,530588853 сут от новолуния 2000-01-06 18:14 UTC, без сети; в южном полушарии серп зеркальный — по настройке). Тема мягко меняется со временем суток; в настоящее полнолуние — особое приветствие, в новолуние — особенно тёмная тема.
- **Отражённый свет.** Девиз мультипровайдерности: Луна не светит сама — она отражает лучшие модели.

## Панели — тайлинг, наш козырь

У Claude Code экран один. У Луны — тайлинговый интерфейс, как редактор в VS Code или тайлинговый оконный менеджер: экран делится на окна-панели, их можно открыть, закрыть, переставить, растянуть, развернуть на весь экран; раскладки сохраняются и переключаются одной клавишей. По умолчанию — одна лента (минимализм), панели — по желанию.

Панели (растёт со временем): **todo и план**, **лимиты** (приливы, деньги, токены), **контекст** (что в нём лежит и сколько весит, фаза луны крупно), **рой** (Звездопад-небо, Спутники на орбитах), **Обратная сторона Луны** (сырые запросы, рассуждения, решения Предохранителя), **файлы и диффы**, **терминал** фоновых задач, **Ниблер**. Любой модуль может добавить свою панель.

## Ниблер — компаньон внизу экрана

Имя — предложение тимлида: питомец Лилы из «Футурамы», с виду милый зверёк, на деле древний сверхразум (и всё та же цитата Бендера про лунапарк). Живёт под полем ввода, говорит короткими репликами в пузыре.

- **Вводит в курс дела.** Вернулся к терминалу — Ниблер в двух строках говорит, что произошло, пока тебя не было, и чего ждут от тебя.
- **Критикует главного агента.** Замечает петли, враньё про «всё готово», выход за рамки задачи, забытые тесты, лишние траты.
- **Видит и его, и его видят.** В Claude Code `/buddy` комментировал, но сам Клод этих реплик не видел — был разрыв. У Ниблера серьёзное замечание может уйти главному агенту заметкой (по настройке: никогда / только серьёзное / всё).
- **Дёшево.** Своя быстрая модель (роль «Ниблер»), читает поток событий, а не весь контекст; говорит редко, только по делу. Выключается одной настройкой; в Луноходе выключен.
- **Характер.** Свои фразы и вид (ASCII), можно сменить на другого компаньона.

## Легендарные фразы

Фразы живут в отдельном файле данных (потом), их можно дополнять и отключать. Ниже стартовый набор.

**Спиннер (пока думает):**
Кумекает (наследие ta) · Сверяется со звёздами · Ловит сигнал с орбиты · Калибрует телескоп · Вычисляет траекторию · Заправляет луноход · Полирует неон · Прогревает реактор · Синхронизирует фазы · Шепчется с нейросетью · Ищет вайфай на орбите · Ставит чайник в шлюзовой камере · Гладит кота Шрёдингера · Переводит эмбеддинги в слова · Считает кратеры · Варит кофе на обратной стороне · Взламывает матрицу (вежливо) · Медитирует на приливы

**Заставка при старте (одна случайная):**
- Лунапарк открыт. Блэкджек — у брата.
- Весим меньше, чем ваш node_modules.
- Ни один npm-пакет не пострадал.
- Отражаю лучшие модели с 2026 года.
- Стартую быстрее, чем OpenClaw успевает сказать «Loading…».
- Луноход заправлен. Куда едем?
- Один маленький шаг для агента…
- На обратной стороне — только твои секреты. Мы туда не смотрим.
- Хьюстон, проблем нет.

**События:**
- ошибка — «Хьюстон, у нас проблема: …»
- отмена — «Возвращаемся на орбиту.»
- конец сессии — «Орёл сел.»
- полнолуние — «Сегодня полнолуние. Контекст бесконечен (нет).»
