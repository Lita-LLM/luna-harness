## 1. Ниблер — компаньон внизу

- Маленький наблюдатель, как `/buddy` у Claude Code, но умнее: смотрит на события главного агента (тулы, ошибки, ответы) и изредка говорит одну строку внизу над вводом — вводит в курс дела («агент третий раз правит один файл»), подсказывает, критикует.
- Мозг — модель роли `fast`, вызывается **редко и дёшево**: по значимым событиям (ошибка, конец хода, долгий ход, повторяющийся паттерн), с дросселем (не чаще раза в N секунд/ходов, настройка). Часть замечаний — без модели, эвристиками.
- Настройка (по умолчанию так): серьёзные замечания уходят главному агенту в следующий ход как пометка; мелкие — только человеку. Выключатель `nibbler.enabled`, частота, роль модели, «говорит ли с агентом».
- Характер — манера (как у главного, механизм из `luna/mind/manners.py`), встроенная по умолчанию — короткий ехидный, но добрый. Пусть сам решает, промолчать ли.
- Событие `nibbler.say` — в [docs/СОБЫТИЯ.md](docs/СОБЫТИЯ.md).

## 2. Панели

Движок тайлинга в `panels.py` уже есть (дерево раскладки, фокус, перемещение, размер, развернуть, `/layout save|load`), панель пока одна — план (todo). Добавь панели, каждая — модуль через `register_panel`, данные — из событий шины:

- **Луна** (контекст и деньги): фаза луны крупно (полублоки, как в `luna/ui/disc.py`) по заполнению контекста, токены вход/выход/кэш, стоимость сессии, модель.
- **Лимиты**: лимиты провайдера, если API их отдаёт (заголовки rate-limit), иначе — «нет данных», без выдумок.
- **Обратная сторона**: всё, что агент делал «за кадром» — лента тулов с аргументами и полными результатами, ошибки, лог; прокрутка.
- **Файлы**: какие файлы сессия читала/меняла, со счётчиком +/- строк; Enter — дифф.
- **Рой**: пока не делать — рой ещё не спроектирован (ЗАДАЧА-11 снята); движок панелей должен позволять добавить её потом одним модулем.
- **Ниблер**: история его замечаний.

Открытие: `/panels` — список панелей с открытием по клавише (пока выбиралки из ЗАДАЧИ-10 нет — простое меню в самой панели или `/panel <имя>`), горячие клавиши на важные. Плавность: появление/закрытие панели — короткая мягкая анимация, отключается `ui.animations`.

## Как потрогать

- `luna try chat` — фальшивый агент: Ниблер говорит, панели наполняются фальшивыми событиями.
- `luna try snapshot panels` — HTML-снимок экрана с открытыми панелями.

## Готово, когда

- Тесты зелёные: панели рисуют данные из событий (без терминала), дроссель Ниблера, маршрутизация его замечаний агенту/человеку.
- В летописи — «как потрогать» и «Для постановщика следующей задачи».
