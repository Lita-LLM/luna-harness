# ЗАДАЧА-08: установка и команда `luna`

Постановщик — тимлид, 31.10.2026. Ветка — `zadacha-08`. Порядок, CI, Git — [AGENTS.md](AGENTS.md). Идёт параллельно с 06, 07, 09 — трогай только новые файлы установки, `README.md` и при необходимости `luna/__main__.py` (одна подкоманда `update`).

## Почему

Сейчас Луна запускается только `python -m luna` из папки проекта. Нужна короткая команда `luna` откуда угодно — без pip, venv и зависимостей (как у Бендера: «распаковал — запустил»).

## Что сделать

1. `install.sh` (Linux, macOS, Termux) и `install.ps1` + `install.bat` (Windows): проверить Python ≥ 3.10, положить лаунчер `luna` в каталог из PATH пользователя (`~/.local/bin`, `$PREFIX/bin` в Termux, `%LOCALAPPDATA%\Luna\bin` на Windows с добавлением в PATH пользователя), без прав администратора. Лаунчер вызывает Python с путём к этой копии репозитория. Повторный запуск — идемпотентен; `--uninstall` — убрать лаунчер (данные `LUNA_HOME` не трогать).
2. `luna update [--check]` — обновление git-копии (`git pull --ff-only` текущей ветки) с понятными сообщениями; без git — подсказка, как обновиться архивом. Опыт Бендера: `bender/updates/git.py` — бери идеи, не тащи слоты и подписи.
3. `luna doctor` показывает, установлен ли лаунчер и в PATH ли он.
4. README: короткий раздел «Установка» (три команды на систему).
5. CI: шаг, который на всех трёх ОС запускает установщик во временный HOME и проверяет `luna --version`.
