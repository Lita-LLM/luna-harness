Постановщик — тимлид (Клод Опус), 31.10.2026. Ветка — `zadacha-01`. Порядок работы, правила и Git — [AGENTS.md](AGENTS.md); прочитай его и [ПЛАН.md](ПЛАН.md) (разделы 2–3), [docs/ДИЗАЙН.md](docs/ДИЗАЙН.md), [docs/research/БЕНДЕР.md](docs/research/БЕНДЕР.md).

## Цель

Фундамент Луны: пакет, ядро (шина, настройки, ошибки, пути), **собственный терминальный рендерер** с градиентами и анимациями, заставка с восходом луны, `luna doctor`, `luna try`, замеры. Агента и моделей пока нет — это ЗАДАЧА следующей вехи. Всё на Python 3.10+ без сторонних пакетов; Windows (Windows Terminal и старая консоль), Linux, macOS, Termux.

## Что сделать

### 1. Пакет и запуск

```
luna/
  __init__.py          __version__ = "0.0.1"
  __main__.py          python -m luna [doctor | try <что> | settings | set <ключ> <значение> | --version]
  core/                ядро — переносится из Бендера (см. ниже)
  ui/                  рендерер и экраны
  diagnostics/doctor.py
  devtools/measure.py
tests/
```

Без аргументов — полноэкранный режим: заставка → минимальный экран. Импорты лёгкие и ленивые: `luna --version` и `luna doctor` не должны тянуть рендерер.

### 2. Ядро — перенести из Бендера

Из `Nickup22/BENDER`: `core/bus.py`, `core/errors.py` (HumanError), `core/ids.py`, `core/paths.py`, `core/pathutil.py`, `core/fsutil.py`, `core/json5.py`, `core/run_lock.py`, `core/dates.py`. Правила переноса — в docs/research/БЕНДЕР.md (строка-комментарий с источником и коммитом, `bender` → `luna`, `BENDER_*` → `LUNA_*`, тесты — тоже).

**Настройки** (`core/settings.py`): возьми идею из Бендера, но напиши компактно.
- Схема в коде: ключ, тип, значение по умолчанию, описание по-русски, допустимые значения.
- Слои: умолчания → глобальный `~/.luna/settings.json` (каталог переопределяется `LUNA_HOME`) → проектный `.luna/settings.json` в текущем каталоге.
- Незнакомые поля в файле сохраняются при записи. Ключи не переименовываются никогда. Запись атомарная.
- Изменение публикует событие на шине — горячая перезагрузка в будущем должна просто подписаться на него.
- В этой вехе схема: `ui.color` (auto / truecolor / 256 / 16 / mono), `ui.unicode` (auto / on / off), `ui.animations` (on / off), `ui.splash` (on / off), `ui.theme` (пока одна тема — `luna`).
- `luna settings` — список с текущими значениями, источником (умолчание / глобально / проект) и описанием. `luna set ui.splash off` — изменить.

### 3. Рендерер (`luna/ui/`) — сердце задачи

Свой, на ANSI. В стандартной библиотеке Windows нет `curses`, и он нам не нужен.

- **Терминал** (`term.py`): альтернативный экран, скрытый курсор, raw-режим (`termios`/`tty` на POSIX; на Windows — `SetConsoleMode` через `ctypes` с включением VT-вывода и VT-ввода). Терминал **всегда** восстанавливается: обычный выход, исключение, Ctrl+C, SIGTERM.
- **Возможности**: определить truecolor / 256 / 16 / моно (`COLORTERM`, `TERM`, `WT_SESSION`, `NO_COLOR` и т. п.) и поддержку юникода; настройки `ui.color` / `ui.unicode` перекрывают автоопределение.
- **Буфер ячеек** (`screen.py`): символ + цвет текста + цвет фона + атрибуты. Двойной буфер; в терминал выводятся **только изменившиеся ячейки** одной записью на кадр. Без мерцания.
- **Ширина символов** (`width.py`): CJK и эмодзи занимают две ячейки (`unicodedata.east_asian_width` плюс диапазоны эмодзи). Строки не съезжают.
- **Цвет** (`color.py`): RGB, градиенты по строке и по прямоугольнику (линейно, несколько опорных цветов), деградация до 256 / 16 / моно. Палитра темы `luna` — из docs/ДИЗАЙН.md.
- **Ввод** (`keys.py`): обычные клавиши, стрелки, Esc-последовательности (с таймаутом, чтобы одиночный Esc работал), Ctrl-сочетания, мышь (SGR 1006: клик, колесо), вставка (bracketed paste), изменение размера окна.
- **Анимации** (`anim.py`): планировщик кадров (до 30 кадров/с) тикает **только пока есть активные анимации**. В простое процесс спит в блокирующем ожидании ввода: никаких циклов опроса. На Windows — ожидание консольного ввода через `ctypes` (`WaitForSingleObject`) или аналог без частого опроса.
- **Луна** (`moon.py`): фаза по проценту 0–100 → 🌑🌒🌓🌔🌕 (и убывающие, если пригодится); запасной вариант без эмодзи — ASCII-набор, придумай красивый.
- **Фразы** (`phrases.json`): спиннер и заставка из docs/ДИЗАЙН.md, раздел «Легендарные фразы». Читаются лениво.
- Если `ui.animations = off` или вывод не в терминал — без анимаций, статично.

### 4. Заставка и минимальный экран

- **Заставка** (`splash.py`): ночное небо с градиентом, мерцающие звёзды, восход луны по фазам, надпись «ЛУНАПАРК» неоновым градиентом (циан → фиолет → маджента) и одна случайная фраза. Не дольше ~1,2 с, любая клавиша пропускает, `ui.splash = off` выключает. В углу — время старта до первого кадра. Это витрина проекта: постарайся, чтобы было красиво.
- **Минимальный экран** после заставки: строка ввода внизу (печать, Backspace, стрелки, вставка), над ней — эхо введённого с пометкой «агент появится в следующей вехе», строка состояния с фазой луны и спиннером из фраз (по Enter спиннер крутится пару секунд — демонстрация). Ctrl+C или `/exit` — чистый выход.
- Рендерер получает данные **только через шину событий**: экран подписан на события, а не вызывает ядро напрямую. Так позже ядро станет отдельным сервером без переделки интерфейса.

### 5. `luna doctor`, `luna try`, замеры

- `luna doctor`: версия Python (≥ 3.10), ОС, терминал и его возможности (цвет, юникод, размер), каталоги `LUNA_HOME` и проекта (доступны ли на запись), источник настроек. Понятные подсказки, что чинить.
- `luna try render`: демонстрационный экран — палитра, градиенты, все фазы луны, спиннер, деградация цвета (все режимы рядом), строка с CJK и эмодзи на проверку ширины, счётчик кадров.
- `luna try splash`: показать заставку ещё раз.
- `luna try measure`: (а) старт до первого кадра — N холодных запусков, медиана; (б) память процесса в простое (POSIX — `resource`, Windows — `GetProcessMemoryInfo` через `ctypes`); (в) загрузка ЦП в простое за 10 с. Итог — таблица в терминал и `--json`.

### 6. Тесты (`unittest`)

Сравнение буферов (выводятся только изменения; поддельный терминал пишет в `StringIO`), градиенты и деградация цвета, ширина символов, разбор клавиш и последовательностей мыши, слои и сохранение незнакомых полей в настройках, фазы луны. `python -m unittest -q` — зелёный.
