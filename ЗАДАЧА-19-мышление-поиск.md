## 1. Мышление: показ, пересказ, effort, анимации

Автор: «показ рассуждений: кроме скрыто и полный — ещё с пересказом быстрой моделью на каждом шаге продумывания (например, каждые 10–30 секунд раздумий), и effort-настройку от minimal до max… и обязательно, чтобы везде были выпендрёжные анимации, особенно где связано с мышлением».

- **Показ рассуждений** — `ui.thinking`: `hidden` (только «думает…» и время), `summary` (по умолчанию: пересказ), `full` (поток как есть). Переключение на лету — `/thinking` (есть с ЗАДАЧИ-16, расширить) и клавишей.
- **Пересказ**: пока модель думает, раз в `ui.thinking_summary_s` (по умолчанию 15 с; и по концу размышления) накопленный кусок рассуждений уходит модели роли `fast` — «одной строкой по-русски: что она сейчас обдумывает». Строки пересказа копятся в ленте под шапкой «думает», полный текст раскрывается Ctrl+O. Дёшево: кусок обрезан, пересказ — короткий; если `fast` не настроена или провайдер не отдаёт текст рассуждений — честно «думает N с» без пересказа. Не задерживать основной стрим (отдельный поток).
- **Effort** — `model.effort`: `auto` (не слать ничего), `none`, `minimal`, `low`, `medium`, `high`, `xhigh`, `max`; на лету — `/effort` выбиралкой и Shift+Tab-подобной клавишей; можно по ролям (`model.effort_fast` и т.п.). Роутер переводит в формат провайдера, неподдерживаемое значение — ближайшее допустимое (а не 400), с пометкой в «Обратной стороне». Свежая картина (ноябрь 2026, по сторонним источникам — **сверь с официальными доками и запиши в `docs/research/EFFORT.md`**):
  - OpenAI (Chat Completions — `reasoning_effort`, Responses — `reasoning.effort`): `none, minimal, low, medium, high, xhigh`, у новейших и `max`; набор зависит от модели (`minimal` — семейство GPT-5, `xhigh` — с 5.2, `max` — 5.6), неверное значение — 400 с перечнем допустимых.
  - Anthropic: адаптивное мышление (`thinking: {type: "adaptive"}`) + `output_config.effort`: `low, medium, high, xhigh, max`; старый `budget_tokens` у новых моделей отдаёт 400, у старых (Haiku 4.5, Opus 4.6) ещё работает — нужна таблица по моделям.
  - Gemini: у 3-го поколения `thinking_level` (у Pro — low/high, у Flash — minimal/low/medium/high), у 2.5 — `thinking_budget` (токены); их нельзя слать вместе; у 2.5 Pro и 3 мышление не выключается. В OpenAI-совместимом слое Gemini есть `reasoning_effort`, но вместе с родными полями — нельзя.
  - OpenRouter: объект `reasoning` (`effort` или `max_tokens`, `enabled`); DeepSeek, Qwen, локальные (Ollama, llama.cpp) — проверь, что принимают.
- **Анимации мышления** (мягкие, по [docs/ДИЗАЙН.md](docs/ДИЗАЙН.md), выключаются `ui.animations`, ЦП в простое ~0): «думает» — не спиннер, а живое: луна медленно наливается светом по длительности раздумья, звёзды вокруг вспыхивают на каждом новом куске рассуждений, строка пересказа проявляется градиентом; глубина effort видна (больше effort — больше орбит/звёзд). Анимации ещё — появление ответа, вызов тула (метеор), сжатие контекста («прилив»), откат (луна отматывает фазу). Снимки кадров — `luna try snapshot thinking --frames`.

## 2. Бесплатный встроенный поиск — как у OpenCode и OpenClaw (заменяет 5-й раздел ЗАДАЧИ-18)

Автор: «быстрые, бесплатные и свободные способы поиска встроенные тоже надо сделать, все ИИ-агенты так делают». **Маскироваться под браузер, чтобы обойти защиту поисковиков от ботов, — не делаем** (это обход защиты; бан прилетит IP автора). Как делают эталоны (сторонние источники, ноябрь 2026 — сверь):
- **OpenCode**: встроенный `websearch` зовёт hosted MCP **Exa** (`https://mcp.exa.ai/mcp`, тул `web_search_exa`) — бесплатно и без ключа в пределах бесплатных лимитов; с ключом — лимиты плана.
- **OpenClaw**: провайдеры по цепочке — Brave (ключ), Perplexity, Exa, Tavily, Gemini/Grok-поиск, **Parallel Search (бесплатный hosted MCP без ключа)**, DuckDuckGo, Ollama Web Search, SearXNG.

Сделать (автор: «если это бесплатно и без авторизации — пусть будет встроено прямо в код базовой Луны»):
- Exa и Parallel — **встроены в ядро** (`luna/tools/web.py` или `luna/net/search/`), работают из коробки без ключей, установки и `mcp.json`; выключатель — общий `web.enabled` и порядок `web.search_providers`.
- Провайдеры поиска как данные, порядок — `web.search_providers` (по умолчанию: `searxng` если задан адрес → `exa` (MCP без ключа) → `parallel` (MCP без ключа) → `duckduckgo`), ключи — через `luna setup` в сейф, для: Exa, Brave, Tavily, Perplexity (опционально). Hosted MCP — через наш MCP-клиент (Streamable HTTP, `luna/mcp/`), отдельный сервер в `mcp.json` человеку заводить не нужно.
- **Родной поиск провайдера модели**, где он есть (Gemini grounding с Google Search, веб-поиск в Responses API OpenAI, серверный web_search у Anthropic) — опция `web.native_search` (по умолчанию выключено: тратит деньги провайдера).
- Ответ тула — единый формат (заголовок, адрес, выдержка, откуда), при провале провайдера — следующий, итог честный.
- Запиши в `docs/research/ПОИСК.md`: кто бесплатен, лимиты, условия использования (не нарушаем ToS), на что переключаться.
- Тесты — на подменённом MCP/HTTP.

## 3. Удаление текущей сессии

Автор: «надо сделать, чтобы текущую сессию тоже можно было удалять». В `/sessions` `d` на текущей — подтверждение, затем удаление в корзину и сразу новая пустая сессия (как `/new`); отдельная команда `/delete` (`/удалить`) — то же для текущей. Отмена `u` возвращает её и переключает обратно.
