# Лунапарк

> «Я построю свой лунапарк! С блэкджеком и…» — Бендер

Свой собственный Claude Code / Codex / OpenCode: сессионный ИИ-агент для работы здесь и сейчас — код, дизайн, анализ, монтаж. Любая модель по любому API, самохостинг, без лишних зависимостей, весит мегабайты и стартует мгновенно.

Третий брат [Блэкджека](https://github.com/Nickup22/blackjack) и [Бендера](https://github.com/Nickup22/BENDER). Наследник `ta` — агента на чистом bash для Termux.

**Статус:** замысел и планирование, кода пока нет.
