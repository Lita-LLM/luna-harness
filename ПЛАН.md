# План

**Статус: черновик v0 от 31.10.2026, ждёт утверждения автором.** Пока он не утверждён, код не пишем. Видение и дизайн-язык — в [docs/ДИЗАЙН.md](docs/ДИЗАЙН.md).

## 1. Что строим одной фразой

Сессионный ИИ-агент уровня Claude Code / Codex / OpenCode на Python 3.10+ без сторонних пакетов. Маленькое ядро-сервер, к которому подключаются клиенты: полноэкранный терминал (главный), встроенный в историю терминала, без интерфейса (скрипты, CI), позже — веб, телефон, редакторы, Бендер.

## 2. Цели по лёгкости (предложение, уточнить замерами в вехе 0)

| что | цель |
|---|---|
| старт до первого кадра | ≤ 200 мс (мечта — 100) |
| память в простое | ≤ 40 МБ |
| ЦП в простое | ~0 %, никаких опросов чаще раза в секунду; анимации только пока что-то происходит |
| код программы без Python | ≤ 10 МБ |
| рендер | ≥ 30 кадров/с, выводим только изменившиеся ячейки |

Импорты необязательного — ленивые. Каждая веха заканчивается таблицей замеров в `ВЕХА-N.md`; ухудшение — повод разбираться, а не «и так сойдёт».

## 3. Архитектура слоями

```
клиенты      TUI (полный / встроенный) · headless `luna -p` · ACP для редакторов · веб/телефон (позже)
               │  события и команды (один протокол, JSON поверх сокета/stdio)
ядро-сервер  шина событий · сессии (журнал JSONL) · настройки со схемой · секреты · чекпоинты
агент        цикл: промпт → модель → тулы → Предохранитель → результат
оркестрация  Спутники (команда) · Звездопад (рой) · Миссии (воркфлоу и макросы)
модели       адаптеры провайдеров · роли моделей · роутер с запасными · зрение у каждого провайдера
тулы         встроенные · MCP (клиент и сервер) · скиллы · хуки · модули
безопасность Предохранитель (одна точка решения) · охранная модель · режимы · песочница
```

### Ядро и сессии

- Сессия — журнал событий в JSONL: продолжить, форкнуть, перемотать, переиграть.
- Чекпоинты — снимки файлов в теневом git: откатить и код, и разговор до любой точки.
- Шина событий — всё, что видит интерфейс, это события; клиент можно отцепить и подцепить другой.

### Самоосознанность и настройка (главная боль автора)

- **Ни одного ручного конфига в обязательном порядке.** Настройка — схема в коде со значением по умолчанию и описанием. Её видно в интерактивном экране настроек и можно менять словами: «поставь охранником быструю модель» — агент сам меняет настройку (с подтверждением, если это ослабляет безопасность).
- **Без перезапуска.** Настройки, провайдеры, MCP, скиллы, темы подхватываются на лету.
- **Луна знает себя.** Встроенный тул `luna` (схема настроек, состояние, документация, `doctor`) — агент отвечает на вопросы о себе и чинит себя сам, не галлюцинируя.
- **Не ломается.** Нет зависимостей — нечему ломаться при обновлении; незнакомые поля в данных сохраняются; ключи настроек никогда не переименовываются (правило Бендера).
- Файл настроек всё равно есть и читается человеком — для тех, кто любит руками.

### Совместимость («чтобы подружились»)

- Читает инструкции проекта: `AGENTS.md`, `CLAUDE.md`, `GEMINI.md` и т. п.
- Понимает скиллы формата `SKILL.md` (открытый стандарт Agent Skills), конфиги MCP от Claude Code / OpenCode / Codex, слэш-команды из `.claude/commands`.
- Говорит по ACP (Agent Client Protocol) — редакторы вроде Zed могут вести Луну.
- Сама может быть MCP-сервером, а Claude Code / Codex / OpenCode могут быть её движками-субагентами (как у Бендера).
- Конкретный список — в исследовании эталонов.

### Модели

- Адаптеры: OpenAI-совместимые (включая OmniRoute, OpenRouter, Ollama, LM Studio, llama.cpp), Anthropic, Gemini. Берём у Бендера.
- Список моделей — прямо из API провайдера, без чужих облачных каталогов.
- **Роли моделей:** главная, быстрая (разведка, сжатие), охранник, зрение, Спутники, Звездопад — у каждой своя модель.
- Роутер с запасными моделями, «Затмение» в интерфейсе, если провайдер упал.
- Подписки и OAuth — только то, что работает точно и легально, без риска бана. Остальное — через OmniRoute.
- Зрение — базовая способность у каждого провайдера: картинки, скриншоты, кадры видео.

### Оркестрация: Спутники, Звездопад, Миссии

Один примитив «агент» (цикл + модель + тулы + права + бюджет), а над ним — разные оркестраторы.

- **Спутники (команда).** Мало агентов, у каждого имя, роль, свои права и память на время проекта. Существуют всегда, но могут спать. Работают скорее последовательно, передают задачи друг другу через почтовый ящик.
- **Звездопад (рой).** 10–10 000 одноразовых микроагентов. Одна задача, крошечный контекст, дешёвая модель, ответ строго по схеме, TTL. Отписались — погасли. Схема map → reduce: разбить → наброситься → свести и проверить. Перед стартом — смета: «2000 метеоров ≈ $3.40, ≈ 4 мин — запускаем?», жёсткий потолок бюджета и параллельности. Для анализа больших данных, ресёрча, извлечения данных, поиска уязвимостей, ревью.
- **Миссии (воркфлоу и макросы).** Заранее собранные сценарии, как в ComfyUI: граф шагов (агент, тул, Звездопад, обычный код, проверка). Запуск — кнопкой, `/команда` или `luna run <миссия>` из скрипта. Пример: «сводка новостей ИИ-компаний за сегодня» с обязательными ссылками на источники и шагом-проверяющим против галлюцинаций; «вырезать пустые моменты из видео». Миссия — файл, которым можно поделиться.

### Тулы

- База: bash (с фоновыми задачами), read/write/edit, glob/grep, веб-поиск и чтение страниц, todo, ask_user, картинки и PDF.
- Код: LSP-клиент, git worktree для параллельной работы, ревью диффов.
- Дизайн и медиа: превью в браузере через CDP (сырой WebSocket), ffmpeg/ImageMagick как внешние программы, если установлены. Остальное — MCP и свои тулы автора.

### Безопасность

Режимы по кругу из ta (обычный → план → ревизор → авто → полный авто), `intent` у опасных действий, охранная модель, список необратимого. Предохранитель Бендера как одна точка решения. Песочница: Linux — bwrap/Landlock, Windows/Termux — честное «песочницы нет, спрашиваю».

## 4. Вехи (черновик)

0. **Каркас.** Структура пакета, ядро-сервер, шина, схема настроек, рендерер (двойной буфер, градиенты, деградация цвета, Windows + POSIX), `luna doctor`, замеры старта и памяти. Можно потрогать: заставка с восходом луны.
1. **Паритет с ta.** Цикл агента, провайдеры, роли моделей, базовые тулы, режимы, охранник, Предохранитель. Минимальный интерфейс.
2. **Красота.** Полноэкранный интерфейс, панели по клавише, диффы, мышь, темы, фазы луны, фразы, картинки в терминале.
3. **Сессии.** Журнал, продолжение, форк, чекпоинты, таймлайн, сжатие контекста.
4. **Самоосознанность.** Тул `luna`, настройка словами, горячая перезагрузка, экран настроек, совместимость с инструкциями и скиллами других харнессов.
5. **Спутники и Звездопад.** Субагенты, команда, рой со сметой и бюджетом, worktree, фоновые задачи.
6. **Расширения.** MCP (клиент и сервер), скиллы, хуки, модули, LSP, ACP.
7. **Миссии.** Формат воркфлоу, запуск из интерфейса и скриптов, первые миссии-образцы.
8. **Клиенты.** Веб-пульт, телефон, связка с Бендером.

Порядок 2–7 обсуждаемый. Вехи 0–1 — обязательный фундамент.
