Только то, что тимлид не может решить сам. Остальное — разумное умолчание плюс настройка (решение от 31.10.2026). Когда автор отвечает, ответ записывается сюда, а решение переезжает в DECISIONS.md.

## Открытые

Пока нет.

## Закрытые

- **Язык** → Python 3.10+, только стандартная библиотека.
- **Интерфейс** → ядро-сервер плюс клиенты, по умолчанию минимализм.
- **Команда и рой** → Спутники и Звездопад; рой запускает агент-мать с видами микроагентов и фиксированными правами.
- **Дизайн и монтаж** → хорошее зрение у каждого провайдера плюс Миссии-конструкторы; узкие тулы — через MCP и позже.
- **Подписки** → только легальные, остальное через OmniRoute.
- **Что бесит в эталонах** → поломки и неудобная настройка; ответ — самоосознанность.
- **Ниблер** → настраивается, по умолчанию серьёзное уходит главному агенту.
- **Код Бендера** → тащить сильно.
- **Порядок вех, лимиты, форматы** → решает тимлид.

Подробности и даты — DECISIONS.md.
