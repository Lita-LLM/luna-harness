# Эталоны: что умеют Claude Code, Codex CLI и OpenCode — и что с этим делать Луне

> Исследование по ЗАДАЧА-02, дата среза — **2026-10-31**. Источники — официальная документация, changelog, репозитории и issues; у каждого факта в подробных разборах стоят ссылка и дата.
>
> Подробные разборы (по 10 вопросам задачи): [Claude Code](эталоны/claude-code.md) · [Codex CLI](эталоны/codex.md) · [OpenCode](эталоны/opencode.md) · [Прочие харнессы и их уникальные идеи](эталоны/прочие.md).
>
> Здесь — синтез: сквозные выводы, вес и старт, что бесит пользователей, чеклист паритета по вехам [ПЛАН.md](../../ПЛАН.md) (раздел 4) и список «взять сверх эталонов».

## 1. Эталоны одной строкой

- **Claude Code** (Anthropic) — самый широкий набор: ~45 тулов, 6 режимов разрешений, 33 события хуков, скиллы, плагины с маркетплейсами, субагенты, экспериментальные Agent Teams, dynamic workflows (оркестрация субагентов JS-скриптами), чекпоинты с откатом, авто-память, fullscreen-рендер. Но: только модели Claude (сторонние шлюзы — лишь как транспорт к Claude), вес и старт официально не публикуются.
- **Codex CLI** (OpenAI) — минималистичные тулы (shell + apply_patch, отдельных read/grep/edit нет), сильная модель безопасности: `sandbox_mode` × `approval_policy` × permission profiles × Starlark-правила команд. Субагенты стабильны и включены по умолчанию, хуки — 12 событий, скиллы по стандарту Agent Skills. Но: бинарь ~306 МБ плюс самообновляющийся демон app-server, встроенного отката файлов нет, документация заметно дрейфует (факты 2025 года мертвы: старые режимы, `[profiles.*]`, `codex mcp-server` удалён, путь скиллов переехал в `.agents/skills`).
- **OpenCode** (Anomaly, ex-SST) — самый открытый: 75+ провайдеров через Models.dev, свои OpenAI-совместимые и локальные модели, нативный ACP, плагины с 27 событиями, `/undo` на git-снапшотах, нативная поддержка SKILL.md (включая пути `.claude/skills`). Но: **две параллельные линии** — V1 (установленная у исполнителя 1.19.3) получает только критические фиксы, разработка ушла в V2 (2.0.0 от 2026-09-11); песочницы нет официально («permissions — UX, не изоляция»); share сессий отменён в v1.19.1 (2026-10-15); LSP в V1 выключен по умолчанию, в V2 серверы не запускаются.
- **Остальной зоопарк** (подробно — в разборе прочих): Gemini CLI для индивидов фактически заменён на Antigravity CLI (анонс Google 19.05.2026, free/Pro/Ultra отключены 18.06.2026); Roo Code закрыт 15.05.2026 (преемники — ZooCode и Cline), Kilo Code пересобран поверх сервера OpenCode; официальный «Grok CLI» — это Grok Build (xAI, бинарь `grok`, репозиторий выложен 14.07.2026). Живые источники идей: Aider (Repo Map, git-нативность), Amp (threads, handoff, oracle), Goose (рецепты), Crush (LSP-контекст, каталог Catwalk), Pi (сознательный минимализм), Mistral Vibe (агенты-пресеты разрешений).

## 2. Сквозные выводы по десяти вопросам

1. **Тулы.** Ядро у всех одно: shell, правки файлов, поиск, веб, todo/план, вопрос пользователю. Различия — в гранулярности: Claude Code и OpenCode дают отдельные read/edit/grep/glob, Codex сознательно оставляет shell + apply_patch. У Луны база из ПЛАН.md совпадает с ядром тройки.
2. **Режимы и разрешения.** Конвергенция к одной схеме: режим (план/обычный/авто) × правила allow/ask/deny по паттернам × OS-песочница для shell. Сильнее всех упакован Codex (профили разрешений + Starlark-правила). У OpenCode песочницы нет вообще — Луне здесь есть чем отличаться (Предохранитель + bwrap/Landlock уже в плане).
3. **Субагенты.** Есть у всех троих; свои типы агентов задаются файлами (`.claude/agents/*.md`, `~/.codex/agents/*.toml`, `.opencode/agents/*.md`). Друг друга субагенты почти нигде не видят: общение — через родителя; исключение — экспериментальные Agent Teams у Claude Code и мультиагент-тулы Codex (spawn/send/wait/close). Worktree-изоляция встроена у Claude Code и Codex, у OpenCode V1 нет. Рой уровня «Звездопад» (сотни одноразовых микроагентов со сметой) не делает никто — ближайший аналог, Kilo Swarm, на порядок скромнее.
4. **Расширения.** Хуки: Claude Code — 33 события, Codex — 12, OpenCode — плагины с 27 событиями и tool.execute.before/after. Скиллы SKILL.md поддерживают все трое — это де-факто стандарт. MCP-клиент есть у всех (stdio + HTTP, OAuth); MCP-сервер «из себя» удалён у Codex (замена — App Server), у Claude Code есть, у OpenCode вместо него свой HTTP API. ACP нативно — только OpenCode; у Claude Code и Codex — внешние адаптеры.
5. **Контекст и сессии.** Автокомпакт есть у всех; resume/fork — у всех. Откат файлов: Claude Code — только правки своих файловых тулов главной сессии (Bash и субагенты не откатываются никогда), OpenCode — git-снапшоты и /undo, Codex — ничего встроенного. Память между сессиями: авто-память Claude Code, экспериментальные memories Codex, у OpenCode — нет. Теневой git из ПЛАН.md Луны покрывает откат шире, чем любой из трёх.
6. **Интерфейс.** Все ушли в полноэкранный TUI; классический рендер Claude Code — источник хронических жалоб на мерцание (#769, #1913), лечится fullscreen-режимом. Темы, кастомная статусная строка и свои фразы спиннера есть у Claude Code и Codex. Компаньон `/buddy` у Claude Code был первоапрельской фичей (v2.1.89) и, по вторичным данным, удалён в v2.1.97, — Ниблер Луны задуман глубже: он читает шину событий и может писать главному агенту. У Codex есть `/pets` (частично подтверждено).
7. **Модели.** Роли моделей есть у всех: отдельная модель субагентов/фона (Claude Code), small_model для мелочей (OpenCode), effort для плана и субагентов (Codex). Свои провайдеры: полностью открыты OpenCode и Codex (включая локальные Ollama/LM Studio), Claude Code закрыт на семейство Claude. Политика Луны (адаптеры + роли + список моделей из API провайдера) совпадает с открытой линией.
8. **Совместимость — что именно читать Луне** (веха 4): `AGENTS.md` (Codex: иерархия root→cwd с лимитом 32 KiB и `AGENTS.override.md`; OpenCode: проектный + `~/.config/opencode/AGENTS.md`), `CLAUDE.md` (иерархия managed→user→project→local; OpenCode V1 читает как fallback, V2 — уже нет), `GEMINI.md` (уходящий формат), скиллы из `.claude/skills`, `.agents/skills`, `.opencode/skills`, `~/.config/opencode/skills`; MCP-конфиги: `.mcp.json` (Claude Code), секция `mcp` в `opencode.json`, `[mcp_servers.*]` в `~/.codex/config.toml`; свои команды из `.claude/commands/*.md` и `.opencode/commands/*.md` (у Codex `~/.codex/prompts/*.md` объявлены deprecated).
9. **Вес и старт** — раздел 3 ниже. Коротко: все трое — сотни мегабайт; это главный количественный анти-эталон для Луны с её целью ≤10 МБ и ≤200 мс.
10. **Что бесит** — раздел 4 ниже.

## 3. Вес и старт

Замеры исполнителя: облачная ВМ, Linux x86_64, 4 vCPU, 7,9 ГБ RAM, 2026-10-31. Мерялась только печать `--version` (не старт TUI) — честная нижняя граница.

| Эталон | Размер | Старт `--version` | Примечание |
|---|---|---|---|
| Codex CLI 0.164.0-alpha.9 | бинарь 306 508 968 байт (~306 МБ) | 10–130 мс (5 запусков) | Плюс демон app-server с 0.157.0 копирует ещё ~374–431 МБ в `~/.codex/packages/` и самообновляется; Arch-пакет 0.166.0 — 355,3 МБ установленным |
| OpenCode 1.19.3 | бинарь 186 013 824 байт (~186 МБ) | 862–1449 мс (5 запусков) | Официальных бенчмарков старта/памяти нет; в CLI зашит авто-heap-snapshot при heap > 2 GiB |
| Claude Code 2.1.314 | официально не публикуется; ~137 МБ нативный бинарь по distinfo FreeBSD-порта | своих замеров нет (локально не установлен) | npm-установка deprecated в пользу нативного инсталлера |

Цель Луны из ПЛАН.md — ≤10 МБ кода и ≤200 мс до первого кадра: по весу это в 14–30 раз меньше эталонов, по старту OpenCode проигрывает цели уже на печати версии.

## 4. Что бесит пользователей (общие темы issues)

- **Регрессии после обновлений** — у всех троих; у OpenCode это кластеры («Another bug after update» #57783, зависания #56941/#57442/#56858, поломки бесплатного тира #55737), у Codex — краши desktop-клиента (#52631, #50567).
- **Тормоза и рендер TUI**: мерцание Claude Code (#769, #1913 — хроническая), ~30% CPU в простое из-за спиннера OpenCode (#22017), лаг при многих проектах в V2 (#52921).
- **Самоходный расход диска**: SQLite TRACE-логгер Codex писал ~640 TB/год (37 TB за 21 день, `~/.codex/logs_2.sqlite`, #28224) — наблюдаемость без тормозов опасна не меньше её отсутствия.
- **Деградация после сжатия контекста**: OpenCode #50103; у Codex компакт падал вместе с недельной квотой Pro (#19585).
- **Лимиты и ложные баннеры**: Codex #23994/#48650 (лимит-баннеры при живой квоте), у Claude Code — главный нерв подписочных лимитов.
- **Внезапные удаления фич**: share (OpenCode), `/buddy` (Claude Code), `codex mcp-server` (Codex) — аргумент за стабильность форматов и правило «ключи настроек не переименовываются».
- **Сложная настройка** провайдеров и конфигов — та же боль, что у автора Луны (см. ЗАМЫСЕЛ); самоосознанность Луны — прямой ответ.

## 6. Что взять сверх эталонов

Идеи, которых нет в ПЛАН.md (источники — разбор прочих и пробелы большой тройки):

1. **Repo Map (Aider)** — карта репозитория: граф символов с ранжированием под бюджет токенов, автоматически в контекст. Дёшево и сильно помогает слабым моделям.
2. **Handoff вместо compaction (Amp)** — при переполнении контекста не ужимать, а собирать ревьюируемый пакет и открывать новую сессию с ним. Кандидат в веху 3 рядом с автокомпактом.
3. **Доска роя (Kilo Swarm)** — `board_post`/`board_read` между главным агентом и потомками. У Спутников в плане есть почтовый ящик, у Звездопада общего канала нет — доска закрывает это.
4. **Автокоммит в основной git (Aider)** — опция рядом с теневыми чекпоинтами: каждая правка агента — коммит с атрибуцией `(aider)`-стиля, `/undo` поверх него.
5. **Безопасный ввод секретов вне видимости модели (Cursor CLI)** — sudo-пароль и ключи вводятся по отдельному каналу, модель их не видит никогда. Прямое усиление Предохранителя.
6. **Oracle как тул (Amp)** — «второе мнение»: спросить другую (сильную) модель по текущему контексту одной кнопкой. Надстройка над ролями моделей.
7. **Агенты-пресеты разрешений (Mistral Vibe)** — режимы `ask`/`accept-edits`/`auto-approve` задаются тем же механизмом, что и субагенты; режим = файл агента.
8. **Пакеты расширений «всё в одном» (Pi packages)** — тулы + скиллы + темы + шаблоны одним устанавливаемым пакетом. Формат для модулей вехи 6.
9. **Внешний каталог моделей — опционально (Crush Catwalk / Models.dev)** — метаданные моделей отдельным открытым каталогом, не зашитым в бинарь; при этом политика Луны «список — из API провайдера» остаётся основной.
10. **GitHub Action для headless (Gemini CLI, Codex Action)** — `luna -p` в CI одной строкой: ревью PR, триаж. Дёшево поверх headless-режима.
11. **Передача сессии между клиентами как фича (Antigravity CLI)** — у Луны клиенты и так сменные архитектурно; оформить явно: начал в терминале — продолжил в вебе/у Бендера.
12. **Самопроверка после компакта** — жалобы на деградацию после сжатий (OpenCode #50103) превратить в метрику: короткий самотест качества после каждого автокомпакта, результат — в журнал сессии.

## 7. Слабые места источников (честно)

- Все три подробных разбора местами упирались в rate-limit читалки: часть страниц сверена по официальным зеркалам/сниппетам, а не построчным открытием, — такие места помечены в файлах разборов.
- OpenAI не публикует единый список тулов, формат rollout-файлов сессий, время старта TUI и расход RAM Codex; Anthropic не публикует размер и старт Claude Code. Цифры по ним — из исходников, портов и issues, с пометками.
- Документация OpenCode V1 обновляется на месте и подсмешивает V2; у Codex дока противоречит сама себе в местах (memories, пути скиллов). Приоритет отдавался специализированным страницам и changelog.
- Линейка моделей GPT-6.x у Codex и привязки алиасов Claude (Fable 5.1 / Opus 5.5 / Sonnet 5.5) подтверждаются только первоисточниками вендоров; независимого консенсуса по ним на дату среза нет.
