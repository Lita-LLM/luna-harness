## Цель

После задачи можно сказать `luna -p "почини сборку"` — и Луна с любой моделью по API читает файлы, запускает команды, правит код, спрашивает подтверждение на опасном и отвечает. Паритет с ta и с базой эталонов.

## Что сделать

1. **Модели** — перенести из Бендера `router/*` и `net/http_client.py`, `net/sse.py`: OpenAI-совместимые (OpenRouter, OmniRoute, Ollama, LM Studio, llama.cpp, DeepSeek…), Anthropic, Gemini. Стриминг текста, рассуждений и вызовов тулов; картинки на входе (зрение) там, где провайдер умеет. Запасные модели при ошибке. Учёт токенов и денег, `context_pct`.
2. **Роли моделей** — `main`, `fast`, `guard`, `vision` (пустая роль = `main`). Настройки со схемой, как в вехе 0.
3. **Настройка без боли** — `luna setup`: провайдер → ключ (ввод скрыт, `getpass`) → список моделей **прямо из API провайдера** → выбор ролей → проверочный запрос. `luna models` — что настроено и живо ли. Секреты — `~/.luna/secrets.json`, права 600 на POSIX, никогда не в логах, не в событиях, не в выводе.
4. **Цикл агента** (основа — `mind/loop.py`, `mind/context.py` Бендера): системный промпт, инструкции проекта (`AGENTS.md`, `CLAUDE.md`, `GEMINI.md` из каталога и выше — по исследованию), вызовы тулов, стрим, очередь сообщений во время хода, прерывание, лимит шагов, защита от зацикливания (одинаковые вызовы подряд → стоп и пометка модели). Всё наружу — только событиями из docs/СОБЫТИЯ.md.
5. **Тулы** (основа — `tools/*` Бендера): `bash` (таймаут, фон, обрезка большого вывода с сохранением в файл), `read`, `write`, `edit` (точная замена), `glob`, `grep`, `web_fetch`, `web_search`, `todo`, `ask_user`. У каждого тула — `intent` от модели для всего, что меняет систему.
6. **Предохранитель** (основа — `guard/*` Бендера + поведение ta): одна функция решения для каждого вызова. Режимы `normal` / `plan` (тулы записи модели не выдаются) / `review` (опасное судит модель-охранник) / `auto` / `yolo`. Правила allow / ask / deny по шаблонам в настройках. Охранник видит только тул и аргументы, без диалога. Список необратимого (`rm -rf`, `dd`, `mkfs`, `curl|sh`, чтение ключей и `.env`, автозапуск) спрашивает даже в `yolo`. Отказ модели — однозначный «НЕ ВЫПОЛНЕНО, не обходи». Утечки: секреты в аргументах `web_fetch`/`bash` и запросы в локальную сеть — повод спросить.
7. **Headless** — `luna -p "задача"`: печатает ответ; `--json` — поток событий построчно (JSONL); `--mode`, `--model`. Подтверждения в headless без терминала — по режиму (по умолчанию отказ с понятным сообщением).
8. **Тесты** — на фальшивой модели (перенести `devtools/fake_llm.py` Бендера): ход с тулами, отказ и `edit` подтверждения, режим `plan`, зацикливание, прерывание, обрезка вывода, ни один секрет не попадает в события. **Сеть в тестах и CI — только фальшивая.**
