# Опись команд и клавиш эталонов (ЗАДАЧА-16, ноябрь 2026)

Свежая сверка по документации и шпаргалкам, актуальным на ноябрь 2026:
Claude Code v2.1.309+ (полная шпаргалка команд/клавиш/флагов, обновлена
в конце октября 2026), OpenCode (официальная документация TUI —
opencode.ai/docs, зеркало mudrii/opencode-docs; линейка 1.x и 2.x),
Codex CLI (шпаргалки и справочники октября 2026). Плюс веха 0:
`docs/research/эталоны/*.md` — там команды разобраны по состоянию на
октябрь; здесь — только интерфейс: слэш-команды, горячие клавиши,
боковые панели и статус-строка.

Колонка «Решение»: **берём** — делаем как у эталона; **по-своему** —
идея та же, механика лунная; **не берём** — противоречит замыслу
(чужие облака, аккаунты, телеметрия) или бессмысленно в Луне.

## Клавиши

| Клавиша | У кого | Решение |
|---|---|---|
| Ctrl+R — поиск по истории ввода | CC | берём: история — выбиралкой с фильтром |
| Esc Esc — rewind | CC, CX | берём по-своему: на пустом вводе — выбиралка ходов к /rewind; во время хода — прежнее прерывание |
| Ctrl+L — перерисовать экран | CC | берём: полный перерендер кадра |
| Ctrl+V — вставить картинку | CC | берём как можем: терминал картинку не отдаёт; путь к файлу картинки из буфера — вложением @файл, текст — текстом |
| Ctrl+G — внешний редактор | CC | берём через /editor (тот же extedit) |
| Ctrl+O — подробности | CC | уже есть (раскрыть запись) |
| Ctrl+T — thinking/задачи | CC, OC | уже есть: панель «План»; показ рассуждений — /thinking |
| Tab — смена агента/режима | OC, CC | уже есть: режимы по кругу; новое — Tab после «/» дополняет команду с описанием |
| Shift+Tab — режимы назад | CC | уже есть |
| Ctrl+P — палитра команд | OC | по-своему: /help — выбиралка с поиском, та же палитра по сути |
| leader Ctrl+X + буква | OC | не берём: у Луны прямые Alt+<панель> и Ctrl-комбинации, лидер — лишняя модальность |
| Alt+P — модель на лету | CC | не берём: /model выбиралкой достаточно |
| Alt+T — thinking | CC | не берём: /thinking командой |
| Ctrl+B — ход в фон | CC | не берём: ходы Луны не фоновятся; фоновый bash — панель «Процессы» |
| Ctrl+C / Ctrl+D — выход | все | уже есть |
| Ctrl+S — спрятать черновик | CC | не берём: черновик и так переживает прерывание (Esc Esc во время хода) |
| ! Tab — история bash | CC | не берём: !команды есть, их история — обычная история ввода (Ctrl+R) |
| ↑/↓ — история | все | уже есть |
| vim-режим ввода | CC | берём: выключатель ui.vim_mode; нормальный режим — h l 0 $ w b x dd, i/a/A — ввод |
| F6 — фокус панелей, стрелки/Enter в панелях | Луна | уже есть (своя механика тайлинга) |

Итого клавиш у эталонов ≈ 48; Луна берёт 6 новых (Ctrl+R, Esc Esc→rewind,
Ctrl+L, Ctrl+V, Tab-дополнение команд, vim-режим) вдобавок к своим.

## Панели и статус-строка эталонов

- **Claude Code**: отдельной боковой панели нет; есть полноэкранный
  /diff рядом с лентой, настраиваемая статус-строка (модель, каталог,
  ветка git, контекст %, стоимость, длительность) и /context сеткой.
- **OpenCode**: сайдбар справа — контекст (токены, %, стоимость),
  MCP-серверы со статусами подключения, LSP-серверы; внизу — модель,
  режим-агент, подсказки клавиш.
- **Codex CLI**: статус — командой /status (модель, effort, права,
  песочница, токены, лимиты плана); дифф — /diff; фоновые терминалы —
  /ps.

Луна берёт: сайдбар-тайлинг у неё уже свой (веха 1–2); новыми тайлами —
Контекст, Git, MCP, Процессы, Дерево файлов, Модели, Диагностика
(LSP не берём: в Луне нет LSP, честный заменитель — вывод последнего
линтера/компилятора/тестов из событий тулов). Статус-строка Луны —
настраиваемая (full/compact/off) вместо чужих скриптов.
