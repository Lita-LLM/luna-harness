# ta (termux-agent) — прародитель

Разбор от 31.10.2026 по README и составу архива [ta.tar.gz](../../ta.tar.gz). Исходники в архиве лежат по пути `data/data/com.termux/files/home/termux-agent/`. Подробности — в его `README.md` и `docs/EXTENDING.md`.

## Что это

CLI-агент для Termux на чистом bash (+ `jq`, `curl`). Около 370 КБ исходников, 34 файла. Чинит сборки, ставит пакеты, правит файлы, ведёт простые проекты. Работает с любой моделью: OpenAI-совместимые, Anthropic, Gemini, локальные (Ollama, LM Studio, llama.cpp).

## Устройство

- `ta` — точка входа; `lib/` — ядро: `agent.sh` (цикл), `stream.sh` (стриминг и мысли), `prompt.sh`, `tools.sh` + `toolparse.sh` + `toolkit.sh` (контракт тулов и хелперы), `guard.sh` (проверка безопасности), `subagent.sh`, `models.sh`, `config.sh`, `ui.sh`/`select.sh`/`input.sh`, `web.sh`, `histfix.sh` (починка истории), `fun.sh`.
- `providers/` — `openai.sh`, `anthropic.sh`, `gemini.sh` поверх одного внутреннего формата истории.
- `tools/` — один файл на тул: `bash`, `read_file`, `write_file`, `edit_file`, `list_dir`, `grep_files`, `web_fetch`, `web_search`, `todo`, `ask_user`, `subagents`. У каждого тула есть мета-поля и контракт (см. EXTENDING.md).

## Что стоит унести в Луну

- **`intent` у опасных действий**: агент одной фразой объясняет, что произойдёт и чем это рискует. Подтверждение — `Enter`/`n`/`e` (править)/`a` (дальше без вопросов)/`q` (стоп всего шага).
- **Режимы по кругу**: обычный → план (тулы записи вообще не выдаются модели) → ревизор (опасное судит отдельная модель) → авто → полный авто. Даже в полном авто узкий список необратимого (`rm -rf`, `dd`, `curl|sh`, чтение ключей, автозапуск) всё равно спрашивает.
- **Охранная модель**: видит только тул и аргументы, без диалога, поэтому её трудно уговорить. Режим `smart` не тратит запрос на очевидное. Сработавший способ выключить мышление у модели запоминается.
- **Отказ однозначен**: модели возвращается «НЕ ВЫПОЛНЕНО» с запретом обходить отказ другим путём.
- **Ввод во время работы** уходит агенту следующим шагом; `Esc Esc` прерывает, и набранное сразу уходит агенту. `@файл` подставляет файл, `!команда` выполняется мимо модели.
- **Защита от утечек**: регулярки секретов в аргументах (`lib/tools.sh`), проверка `web_fetch` на localhost, частные адреса и токены в URL.
- **Удобство моделей**: `ta setup` берёт список моделей прямо из API, есть профили моделей, `ta doctor`, «когда модель залипает».
- **Версия 2**: метки тулов, чекпоинты и откат, прерывание длинных операций, рассуждения у своих провайдеров.
- **Память, сессии, субагенты, долгие команды с большим выводом, стриминг мыслей.**

## Чего не хватает (почему нужна Луна)

Bash ограничивает: нет мультиплатформы, нет красивого интерфейса, сложно делать параллельность, модули, MCP, LSP, картинки и всё «на богатом». По словам автора, до Claude Code ta далеко, это «нано-версия».
