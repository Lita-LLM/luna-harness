## 1. Фундамент `luna/agents/`

- **Порождение ребёнка**: `Agent` из `luna/mind/loop.py` с своим промптом, тулами, моделью (роль или конкретная), бюджетом (шаги, токены, деньги, время), именем. Работает в своём потоке; события — на общую шину хозяина с полями `agent_id`, `parent_id`, `kind` (`assistant` / `satellite`, позже `cell`), `name`. Контракт событий — раздел 9 docs/РОЙ.md, допиши в [docs/СОБЫТИЯ.md](docs/СОБЫТИЯ.md).
- **Права ребёнка ⊆ права родителя.** Опасные действия ребёнка идут через Предохранитель хозяина, вопрос человеку помечен, от кого он («Кодер1 хочет…»). Тест обязателен: ребёнку нельзя выдать больше, чем есть у родителя.
- **Порождение детей**: по умолчанию звать детей могут только полноценные агенты — главный и спутники. Настройка `agents.max_depth` (по умолчанию 1) и флаг у ребёнка. Тест на запрет.
- **Бюджет**: общий кошелёк сессии `agents.session_budget_usd` (по умолчанию 5), все дети тратят из него; упёрлись — ребёнок останавливается и сдаёт, что успел. Локальные модели — считаем токены и время. Событие `budget.update` с прогнозом.
- **Почта**: у каждого агента входящие; сообщение — событие `agent.message` (`from`, `to`, `text`); сообщение будит спящего. Кто кому может писать — правило у родителя (раздел 3 docs/РОЙ.md). Сделай почту общей — рой позже будет слать по адресам через неё же.
- Хозяину — **сводка**, а не весь лог ребёнка: контекст хозяина не пухнет. Полный лог — в журнале сессии и в «Обратной стороне».
- Прерывание (Esc) хозяина гасит всех детей. Сессия на диске помнит спутников (имя, роль, модель, история) — `--continue` их возвращает спящими.

## 2. Ассистенты

- Тул `assistant` (имя на твоё усмотрение): «временный, но большой агент, экономная опция, полные возможности» — хозяин отдаёт задание, ассистент работает до сдачи, отвечает только хозяину. Можно несколько параллельно. Модель по умолчанию — роль `fast`, хозяин может указать другую.

## 3. Спутники

- Тул `crew`: создать спутника (имя, роль, модель/провайдер, промпт роли), дать задание, написать ему, разбудить, усыпить, распустить, список. Разные провайдеры в одной команде — наш козырь.
- Спутники пишут **друг другу по именам** (`Кодер1 → Тимлид`), «пинают» друг друга, можно назначить **лидера** (ему по умолчанию идут отчёты, он раздаёт работу). Спящий не тратит ничего.
- Для работы с кодом спутник может получить свой git worktree (по флагу при создании); слияние — через хозяина. Без git — работает в каталоге проекта, но запись в файлы, которые сейчас правит другой спутник, — с предупреждением.
- Команда как данные: состав можно сохранить и загрузить (`LUNA_HOME/crews/`, `.luna/crews/`) — «моя обычная команда: тимлид + два кодера + ревьюер».

## 4. Как видно

- Панель **«Экипаж»**: список агентов-детей — имя, вид, роль, модель, состояние (думает / действует / ждёт / спит / сдал / упал), токены, деньги; последние письма между ними.
- В панели «Луна» (ЗАДАЧА-14, `luna/ui/panels/`) — строка общего бюджета и прогноза; если для этого нужен новый модуль данных — сделай его, панель «Луна» тронь минимально.
- Созвездие роя — в ЗАДАЧЕ-15, не здесь.

## Как потрогать

- `luna try crew` — на фальшивой модели: хозяин создаёт трёх спутников, лидер раздаёт работу, они переписываются, один упирается в бюджет; в конце — сводка и лента событий текстом.
- `luna try chat` — фальшивый агент показывает панель «Экипаж» с данными.

## Готово, когда

- Тесты зелёные: права ⊆ родителя, запрет порождения сверх глубины, бюджет обрывает, почта по правилам, прерывание гасит всех, спутники переживают `--continue`.
